# 核心概念与愿景入口 (AGENTS.md)

本目录用于记录 AICoach 产品的核心愿景、用户画像、核心循环等基础指导概念。在 Harness Engineering 中，这些概念是防止 Agent 产生功能蔓延的终极“指南针”。

## 内容地图

- `vision.md`: 产品的核心愿景（帮助知识工作者稳定完成任务，建立教练依赖感）。
- `mvp_scope.md`: 核心产品的边界和红线（绝对不可随意扩展的功能范围）。
- `user_persona.md`: 目标用户的画像分析。
- `cool_loop.md`: 核心产品闭环机制（计划 -> 执行 -> 复盘 -> 再计划）。

## 维护原则

- **愿景守护**: 所有工程和设计决策（无论是人类还是 Agent 做出）都必须服务于本目录中定义的愿景，不得擅自修改整体目标。
- **关联引用**: 任何产品规格或 Prompt 的变更，都应该能追溯到这里的核心概念。
