# 核心闭环（Core Loop）

## 流程

1. 用户输入目标
   - 今日想完成的事情
   - 当前状态（可选）

2. AI生成计划（Planner）
   - 控制任务数量（3–5个）
   - 安排时间块
   - 提供完成标准

3. 用户执行
   - 勾选任务
   - 系统记录行为

4. AI干预（Coach）
   - 长时间未执行 → 提醒
   - 卡住 → 拆解任务
   - 状态差 → 调整任务类型

5. AI复盘（Review）
   - 计算完成率
   - 分析行为问题
   - 提供优化建议

6. 调整策略
   - 下次生成计划时应用

## 核心指标
- 日活（是否每天使用）
- 完成率（60–80%为最佳区间）
- 连续使用天数
