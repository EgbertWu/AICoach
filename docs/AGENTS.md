# Docs 目录导航 (AGENTS.md)

这是 AICoach 项目的文档中心，采用了 Harness Engineering 和 AI Agent 开发最佳实践进行分类。所有的“约束即产品 (Spec as Product)”都在此定义。

## 目录结构 (Directory Map)

| 目录 | 内容 | 说明 |
| --- | --- | --- |
| **[`concepts/`](./concepts/AGENTS.md)** | 核心概念与愿景 | 存放产品的核心愿景（Vision）、用户画像、核心循环等指导性概念。 |
| **[`design-docs/`](./design-docs/AGENTS.MD)** | 架构与接口设计 | 包含系统的核心架构、接口规范（如 Hashline 协议）设计。 |
| **[`exec-plans/`](./exec-plans/AGENTS.MD)** | 执行计划与技术债 | 记录当前执行计划（Sprint）、历史归档以及“代码库免疫系统”追踪的技术债。 |
| **[`product-specs/`](./product-specs/AGENTS.md)** | 产品规格与评估 | 存放 API 规格、功能详细规格、状态机，以及用于“机械化执行”的自动化评估和测试指标（Harness 核心区）。 |
| **[`prompts/`](./prompts/AGENTS.md)** | 提示词积累 | 沉淀在学习和实践过程中验证有效的 AI Coach 核心 Prompt。 |
| **[`feedback/`](./feedback/AGENTS.md)** | 反馈记录 | 记录在开发和实践过程中的踩坑、修正、迭代心得。 |
| **[`generated/`](./generated/AGENTS.md)** | 生成物与模型 | 存放通过 Agent 或工具自动化生成的数据模型（Data Model）及衍生代码。 |
| **[`references/`](./references/AGENTS.md)** | 外部资源 | 整理和索引与 Harness Engineering 相关的外部文章、仓库、工具等。 |

---
*维护原则：无论你（Agent）接到的任务是什么，在动手前都必须查阅相应的目录，确保行动符合这套规则系统。*
